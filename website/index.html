One store. Typed records.

Every record has a kind, an owner, and a source.

Writes reconcile against existing records before they persist. Reads filter by owner, scope, and metadata, then rank what remains. SQLite holds everything; per-owner indexes rebuild from it.

01 · Write path

Reconciliation

Exact duplicates attach as evidence; an explicit decision supersedes a record or flags a conflict.
  • Revision-checked writes
  • Source references kept

02 · Task context

Preferences

Every rule that applies to a task is returned, independent of search rank.
  • Project exceptions override
  • Conflicts surfaced

03 · Maintenance

Dreams

Bounded consolidation passes propose merges; applying a plan is a separate step.
  • Plan, then apply
  • History archived

Pythonic by design

From zero to durable memory in a few lines.

SQLite ships with Python and the tables create themselves. Bring an embedder, or pass vectors directly.

quickstart.py Python 3.12+ 
from memory_core import Database, EmbeddingSpec, MemoryService
from memory_core.memory.models import PreferenceMemory, RememberRequest, TaskContext

memory = MemoryService(
    Database("./memory.db"),
    embedding_spec=EmbeddingSpec(model_id="minilm", revision="1", dimensions=384),
    embedder=my_embedder,
)

await memory.call(
    RememberRequest(memory=PreferenceMemory(
        summary="Use uv for Python dependencies.",
        preference_key="python.package_manager",
        value="uv",
        applicability={"languages": ["python"]},
    )),
    owner_id="alice",
)

prefs = await memory.resolve_prefs(
    TaskContext(task_id="edit-api", attributes={"languages": ["python"]}),
    owner_id="alice",
)
persisted to SQLite owner index updated ready to recall
